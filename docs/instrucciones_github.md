# Instrucciones para subir el prototipo a GitHub

## 1. Crear el repositorio

1. Entrar a GitHub.
2. Hacer clic en **New repository**.
3. Usar el nombre:

```text
prototipo-acceso-educativo-el-cocuy
```

4. Seleccionar visibilidad **Public** para que el tutor tenga acceso de lectura.
5. No marcar la opcion de crear README, .gitignore o licencia, porque el proyecto ya incluye esos archivos.
6. Hacer clic en **Create repository**.

## 2. Subir los archivos

Subir el contenido de la carpeta del proyecto, no el archivo ZIP. La estructura debe quedar asi:

```text
app.py
requirements.txt
README.md
.gitignore
data/datos_acceso_educativo_el_cocuy.csv
docs/instrucciones_github.md
docs/guion_video_10_min.md
docs/evidencia_trl5.md
```

## 3. Confirmar cambios

En el mensaje del commit escribir:

```text
Carga inicial del prototipo funcional TRL5
```

Luego hacer clic en **Commit changes**.

## 4. Verificar el enlace

El enlace final debe tener una forma similar a esta:

```text
https://github.com/USUARIO/prototipo-acceso-educativo-el-cocuy
```

Ese enlace se debe incluir en el anexo del documento maestro como repositorio GitHub con acceso de lectura.
